# Maske 用户旅程

## 要解决的问题

| 场景 | 现在怎么做 | 问题 |
|---|---|---|
| 租房、入职、酒店、银行以外的机构要证件复印件 | 直接拍照发过去 | 对方拿到了个人号码、MRZ、条码、照片，可以拿去冒用 |
| 荷兰人用 KopieID | 只支持荷兰证件 | 外国人的护照、居留卡、外国驾照都用不了 |
| 用修图软件自己涂 | 手动涂黑、加文字 | 麻烦，容易漏掉 MRZ 和条码，模糊处理可以被还原，照片里还带着位置信息 |

## 流程

```
打开
  └─ 一个画面：「扫描证件」· 「选择照片」· 「选择文件」
       底部一行：「离线使用，不保留任何内容」· 「支持的证件」
  └─ 点扫描时才请求相机权限（系统文档扫描器，自动裁边，正反面都可以拍）

审阅
  └─ 标题：🇳🇴 护照 · 挪威（认不出来时提示“请自己加框”）
  └─ 证件图上：不透明蓝灰遮罩 = 会被遮住；虚线框 = 不遮
       点遮罩直接调整：四角拖动、放大、隐藏开关、重置、取消、保存
       右上角「加框」后可以拖出自己的框
  └─ 下方按类型的开关：照片 · 个人号码 · 证件号 · 地址 · MRZ · 条码
  └─ 「继续」

水印
  └─ 预览最终的副本
  └─ 「接收方」（必填）·「用途」（选填）；日期自动
  └─ 「分享副本」→ 系统分享面板
  └─ 「完成」→ 清空内存和临时文件，回到首页
```

## 原则

- 每个画面只回答一个问题：首页回答“证件从哪来”，审阅回答“遮哪些”，水印回答“给谁”。
- 自动检测只给建议，默认全部遮住；用户可以通过开关显示，也可以放大后调整四角。
- 遮挡是把像素直接涂掉，不用模糊；副本缩小尺寸、不带元数据。接收方、用途、日期放在证件下方，每页只保留一道淡水印。
- 不保存任何东西，切到后台时盖住画面。
- 只用系统控件；配色只有纸白、墨黑和一种冷蓝，北欧式的安静。
- 界面要 self-explanatory，操作靠直接交互和短标签表达，不放大段 explanation text。
