# MaskCopy 使用流程

## 首页

一个扫描入口，下方 Photos / Files。右上角查看支持的证件。无大插画、口号、介绍段落或步骤条。

## 遮挡

先看证件，再看可直接开关的敏感项目。拖遮罩移动整块；点击进入放大编辑，拖四角改边界。在编辑器中，拖遮罩移动，拖周围区域平移图片。增加遮罩使用右上角 Add box。Continue 进入水印。

## 水印

填写接收方、用途，日期自动带入。键盘 Next 移到下一项，Done 收起键盘。Preview copy 生成副本并进入最终预览。输入文字时不渲染图片。

## 保存与分享

最终页直接选择 JPG / PDF，再点击 Save 或 Share。Save 打开系统文件保存位置，成功后原按钮变为勾号和 Saved。Share 打开系统分享面板，使用已选格式。Close 明确表示关闭当前流程，不再用 Done 表示清空。

PDF 是与预览一致的单张合成图片页，正反面仍按预览合并；没有原始图片、文字层、批注或元数据字典。用户保存到目标位置的副本继续保留，应用的临时工作文件会清理。

## 动效

扫描按钮轻按反馈、遮罩拿起反馈、保存勾号切换和原生页面转场。不做装饰性循环或进场等待。减少动态效果关闭自定义按压缩放。识别、成品渲染和文件编码不在拖动或动画帧里运行。真机帧率仍需设备测试。
