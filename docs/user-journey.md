# MaskCopy 用户旅程

## 主页

扫描是主操作，相册和文件是次级入口。首页只展示证件遮挡图形和操作，不放介绍段落。Documents 可查支持的国家。

## 遮挡

导入后立即显示打开或识别状态，可取消。识别结束后展示矫正后的证件、实心遮罩和直接可见的字段开关。点击遮罩可精调；Add box 用于补漏。

编辑器支持原生捏合、双击缩放和平移。四角手柄始终保持同样的屏幕触控尺寸。Save 改变实际导出多边形，Cancel 放弃本次调整。

## 水印

填写收件人和用途，日期取自当前会话。键盘 Next/Done 切换和结束输入，当前输入框滚动到键盘上方。输入期间不生成图片。

Preview copy 在后台生成一次最终副本。返回改字或修改遮罩后才重新生成；内容相同则复用已有副本。

## 分享

展示与分享文件一致的最终像素，支持原生缩放和检查。每页都有收件人、用途及日期组成的斜向水印。底图上是深色字，遮罩上是浅色字。Share copy 才生成临时 JPEG，并打开系统分享面板。

Done、返回主页或下一次启动会清理临时文件。不保存证件历史、不上传识别、不建立账户。

## 必须继续验证

真实 iPhone 的拍摄、反光、侧拍、识别耗时、动画帧率和辅助功能不能用模拟器结果替代。不得收集用户的真实证件做测试。优先使用打印的官方 specimen 和合成文件。
