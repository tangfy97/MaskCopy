# Documents and watermark refinement

The owner rejected the dense country-first information page and the decorated watermark that crossed important fields. Preserve the quiet Home, native glass controls, direct masks and explicit JPG/PDF export.

## Evidence and direction

RvIG’s official KopieID FAQ specifies recipient, purpose and date. Its official watermark illustration shows direct diagonal lettering rather than a certificate-style stamp. The illustration is a marketing diagram, not proof of the app’s exact colour, opacity or current pixels. The App Store description confirms the same recipient/purpose/date workflow. No competitor artwork or code is bundled.

The first local SwiftUI document-category query returned no applicable result. A narrower list/navigation query supported using native List; its broader navigation prescriptions were not treated as a reason to refactor this small read-only flow. The implementation preserves the existing theme.

## Implementation

Documents opens with four full document names and their relevant sides, not abbreviations under emoji country rows. Type navigation filters the existing country-profile table. A separate searchable Countries list opens each country’s document names. Include a short photos/PDF import label and review reminder; avoid an introductory explanation paragraph.

The watermark is two same-weight/same-size lines at 30 degrees: Copy for recipient; purpose and date. Remove rules, the large recipient and tiny caption. Red translucent lettering uses multiply over the document, so pure black printing is retained exactly before JPEG encoding. A light clipped pass remains visible over opaque redactions. All pixels remain flattened with unchanged opaque masks; preview, JPG and image-only PDF share the same output. Update PRIVACY because the exported treatment changes.

## Limits and verification

This is a blending/readability fix, not OCR-aware field avoidance. Coloured/faint printing and unusually dense layouts require visual review. Long text still shrinks. Do not claim watermarks cannot be removed or prevent all reuse. Check normal and maximum-text native navigation, short/long recipient previews, keyboard/recovery, actual PDF saving, mask opacity, every-page marking, black-print preservation and flattened export. Recognition rules are unchanged.
